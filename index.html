How I work

Good decisions need
something to react to.

01

Make it tangible.

I use working prototypes to test behavior and turn abstract disagreements into decisions people can try.

02

Find the simpler answer.

I work with engineering early. Sometimes the best design decision is removing a choice that never needed to be there.

03

Connect the details.

I use product work to improve shared patterns, so a solution can help more than one screen or team.
